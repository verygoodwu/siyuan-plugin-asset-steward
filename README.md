不再需要一个独立的记账 App——把资产、流水和规划直接放进你的笔记里，和知识库一起多端同步。

> v1.1.0：加入手机端快速记账、基础总览和流水搜索，同时修复同步导致的界面闪烁。手机端账户编辑、规划和完整报表请在桌面端使用。实体iOS/Android及系统软键盘尚未验证。

## ✨ 功能特性

### 📱 手机端
- 启用插件后，从顶栏「记一笔」或侧滑面板「资产管家」打开手机界面。
- 支持收入/支出快速记账、分类与账户选择、基础资产总览、最近流水和关键词搜索。
- 请先在桌面端添加账户。账户编辑、规划、完整报表以及流水编辑/删除暂在桌面端使用。
- 手机与桌面共用账本，跨设备更新需要思源同步完成；收到外部更新时会保护未提交输入。
- 已通过触屏浏览器及320/390/430像素宽度模拟检查，iOS/Android实体设备和系统软键盘仍待反馈。

### 📊 总览
- **净资产 / 总资产 / 总负债 / 月预算** 一屏掌握
- **每日净资产快照**：每次打开思源自动记录一个点，坚持使用即可看到真实净值趋势（不造假数据）
- **资产构成环图** + 收支概况表（本周 / 本月 / 今年，含环比箭头）
- **今日待办**：来自真实数据的额度预警与 7 天内到期扣费提醒

### ✍️ 记账
- 支出 / 收入分类快捷选择，支持**自定义分类**（带 emoji 选择器）
- 备注支持 `#标签`，流水可筛选、搜索、编辑、删除
- 一键导出 CSV

### 🏦 资产与负债
- **五分组**管理：💧 现金流 / 📈 投资资产 / 🏠 固定资产 / 💎 贵重物品 / 🔻 负债
- 内置常见银行卡、支付宝、微信、花呗、京东白条、借呗等类型模板
- 信贷类账户支持**额度、已用、月支出上限**，超阈值自动预警
- 编辑模式：行内添加 / 修改 / 上下排序 / 删除二次确认（支持"今天不再弹出"）

### 📅 规划
- **订阅 & 固定支出**：自动折算月付（年付 / 周付 / 月付），下次扣费倒计时
- **保险保单**：缴费周期与月均负担追踪
- **贷款规划**：等额本息 / 等额本金双方式，自动计算月供、剩余本金、预计剩余利息与还款进度条
- **储蓄计划**：目标 / 已存 / 每月自动转入 / 年化利率与**利息估算** / 达成期限（超期预警）

### 📈 报表
- 近 6 个月收支对比、本月支出分类占比、近 30 天消费趋势（全部 Canvas 手绘，零外部依赖，悬浮显示数值）
- **消费诊断**：分类环比暴涨 >20%、单类占比 >35%、日均超预算等规则自动提示
- AI 财务点评（规则生成，规划中接入 DeepSeek）

## 🚀 使用入口

| 入口 | 功能 |
|---|---|
| 右下角 Dock 图标 | 打开 / 关闭完整界面（点一下打开，再点关闭） |
| 顶栏 · 钱包图标 | 快速记一笔（弹窗，不离开当前页面） |
| 顶栏 · 四宫格图标 | 打开 / 关闭完整界面（与 Dock 等效） |

**首次使用**：打开完整界面 → 资产页 → 点击「✏️ 编辑」→ 在分组下添加你的账户 → 开始记账。

## 🔒 数据说明

- 所有数据保存在思源笔记内（`data/storage/petal/asset-steward/`），**不经过任何第三方服务器**
- 开启思源云同步后，多台设备自动共享同一份账本
- 卸载插件前如需备份，直接复制上述目录即可
